## 1. コントラスト強調

錆・汚れ・逆光などで文字がぼんやりしている画像を、AI が読みやすい状態に補正する処理です。

| パラメータ | 現在値 | 意味 |
|---|---|---|
| スキップ閾値 | `12` | 明暗差がこの値未満の画像は「すでに十分クリア」と判断して補正しない |
| 引き伸ばし上限 | `2.2倍` | 明暗差を広げすぎると白飛び・ノイズが増えるため上限を設定 |
| 底上げ量 | `+8` | 全体的に暗い画像を少し明るくして黒つぶれを防ぐ |

**調整の目安**
- 屋内・暗い環境で文字が見えにくい → スキップ閾値を下げる（例: `5`）
- 白飛びが多い → 引き伸ばし上限を下げる（例: `1.8`）

## 2. 文字領域検出（BFS）

確率マップ上で「文字らしいピクセル」をつなぎ合わせて、文字の塊を見つける処理です。

| パラメータ | 現在値 | 意味 |
|---|---|---|
| 検出閾値 | `0.18` | この確率以上のピクセルを「文字候補」とみなす。低いほど感度が上がり、暗い環境でも検出しやすくなる |
| 最小ピクセル数 | `15` | この画素数に満たない塊はノイズとして除外する。小さい値ほど細い文字も拾う |
| 最大検出領域数 | `24` | 1枚の画像から処理する文字領域の上限。多いほど認識範囲が広がるが処理時間も増える |
| 最小面積 | `120px²` | 極小のノイズ領域を除外するための追加フィルタ |

**調整の目安**
- 鉄骨刻印（屋外・明るい・打刻文字）は閾値を上げる（`0.26`）と誤検出が減る
- 液晶画面・チョーク文字・暗い環境は閾値を下げる（`0.18`）と検出感度が上がる
- 背景のノイズが文字として誤検出される → 最小ピクセル数を増やす（例: `24`）

---

## 3. 文字領域の拡張（expandPolygon）

検出した矩形を切り出し前に少し広げ、文字端が切れないようにします。

| パラメータ | 現在値 | 意味 |
|---|---|---|
| 横方向スケール | `1.10倍` | 左右に 10% 広げる。広げすぎると隣の文字が混入する |
| 縦方向スケール | `1.30倍` | 上下に 30% 広げる。鉄骨刻印は縦方向の余白が少ないため大きめに設定 |

**調整の目安**
- 文字の上下が切れて認識が悪い → 縦方向スケールを増やす（例: `1.5`）
- 隣の行の文字が混入する → 縦方向スケールを減らす（例: `1.1`）

## 4. 同一行ポリゴン結合（mergeNearbyLinePolygons）

> **ver1.8 新機能**

1つの製品コードが途中で分割検出された場合（例: `B1Sb3ON-16` が `B1Sb3ON` と `-16` に分かれる）に、認識前に1つにまとめます。

| パラメータ | 現在値 | 意味 |
|---|---|---|
| 縦重なり率 | `0.45` | 2つの領域が縦方向に 45% 以上重なっていれば「同じ行」と判断 |
| 中心Y差の許容 | 高さの `0.3倍` | 中心の高さがこの範囲内なら同じ行とみなす |
| 横ギャップの上限 | 高さの `2.0倍` | 領域間の横方向の距離がこれより広いと別の文字列と判断 |
| 高さ比率の上限 | `2.5倍` | 2つの領域の高さの比がこれを超えると結合しない（縦書きと横書きの混在防止） |

## 5. カラーマージ抑制（MergeColorCategory）

> **ver1.8 新機能（内部処理）**

隣接する文字領域を結合するとき、色が明らかに異なる領域同士は誤結合しない内部制御です。ユーザー向けの操作は不要です。

| パラメータ | 現在値 | 意味 |
|---|---|---|
| 最小彩度 | `0.18` | この彩度以下のピクセルは「無彩色（白・灰・黒）」と判断して色分類対象外 |
| 最小明度 | `0.25` | 暗すぎるピクセルは色の判断が難しいので除外 |
| 有効ピクセル率 | `1%` | 画像内で条件を満たすピクセルが 1% 未満なら「色なし」と判断し、制限を適用しない |

## 6. 文字認識・向き比較

まず正位置（0°）で認識し、信頼度が低ければ上下逆（180°）でも試して良い方を採用します。

| パラメータ | 現在値 | 意味 |
|---|---|---|
| 早期終了・信頼度 | `0.62以上` | 0° の認識信頼度がこれ以上なら 180° の確認をスキップして高速化 |
| 早期終了・有効文字率 | `0.75以上` | 英数字・`-`・`/` の割合がこれ以上なら信頼できると判断 |
| 早期終了・有効文字数 | `4文字以上` | 短すぎる認識結果は偶然一致の可能性があるので早期終了しない |

**認識スコアの計算式（0° vs 180° の比較に使用）**

```
スコア = 信頼度 × 0.80
       + 有効文字率（英数字の割合）× 0.15
       + 文字数ボーナス（最大 24 文字）× 0.002
```

> 信頼度だけで比較すると「短い誤認識が高スコアになりやすい」問題があるため、文字数と有効文字率を加味しています。

## 7. 画質フィルタ（isUsefulCropForOcr）

切り出した画像が「文字がいるはずがない」と判断されたら認識をスキップします。

| 除外条件 | 判定基準 | 除外例 |
|---|---|---|
| ほぼ真っ白 | 明るいピクセル 96% 以上 + 彩色なし + コントラスト 35 未満 | 白壁・空白部分 |
| 色も輪郭もない | 彩色ピクセル 0.2% 以下 + 輪郭ピクセル 0.3% 以下 | 一様な錆面 |
| 絶対数が少なすぎ | 彩色ピクセル 2 個以下 + 輪郭ピクセル 3 個以下 | 極小ノイズ |

---

## 8. 認識後フィルタ（isUsefulOcrResult）

認識結果のテキストが明らかに不正な場合に除外します。

| 除外条件 | 判定基準 |
|---|---|
| テキストが空 | 認識失敗 |
| エラートークン | `EMPTY` / `FORMATERR` / `ERROR` |
| 有効文字がゼロ | `@#%!` など記号のみ |
| 有効文字率が低い | 英数字・`-`・`/` の割合が 45% 未満 |
| 短い低信頼 | 2 文字以下 かつ 信頼度 60% 未満 |

## 9. 数値変更の影響早見表

| やりたいこと | 変更するパラメータ | 方向 |
|---|---|---|
| 暗い環境での検出を増やしたい | BFS 検出閾値 | 下げる（`0.18` → `0.14`） |
| 背景ノイズの誤検出を減らしたい | BFS 検出閾値 / 最小ピクセル数 | 上げる（`0.26` / `24`） |
| 文字端の切れを減らしたい | 縦方向スケール | 上げる（`1.30` → `1.5`） |
| 隣の行の文字混入を減らしたい | 縦方向スケール | 下げる（`1.30` → `1.1`） |
| 処理速度を上げたい | 最大検出領域数 | 下げる（`24` → `12`） |
| 長い製品コードの認識精度を上げたい | `MAX_REC_WIDTH` | 上げる（現在 `1920`） |
| 錆・汚れが多い環境でのコントラスト調整 | スキップ閾値 | 下げる（`12` → `5`） |
