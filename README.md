# Cross Vision F

**鉄骨工程管理 Android アプリケーション**

Cross Vision F は、鉄骨の工程管理を効率化するための Android アプリです。スマートフォンのカメラで鉄骨に手書きされた製品番号を撮影し、OCR（光学文字認識）で自動読み取りを行います。複数製品の一括登録やオフライン環境での使用にも対応しています。

---

## 主な機能

### 📸 複数製品の一括読取
1回の撮影で最大5本の製品番号を同時に検出し、リスト表示します。誤認識があった場合はその場で手動修正や削除が可能です。

### 📡 オフライン対応
電波の届かない現場でも OCR 処理と登録操作が可能です。登録データは端末内に一時保存され、オンライン復帰時にクラウドへ自動同期されます。

### ✏️ 手動修正・追加
OCR の認識結果をユーザーが確認・編集できるほか、認識されなかった製品コードを手動で追加することもできます。

### 📋 登録履歴管理
過去の登録データを一覧・検索でき、同期ステータス（未送信/送信中/送信済/失敗）も確認できます。

## 画面構成

| 画面 | 説明 |
|------|------|
| ログイン | ユーザーID・パスワードによる認証 |
| 工事・工程選択 | 対象区分（製品/部品/置き場）の選択、工事名と工程名をプルダウンで選択 |
| 画像認識 | カメラ撮影またはギャラリーから画像を選択 |
| カメラ | CameraX によるリアルタイムプレビューと撮影 |
| 認識結果確認 | OCR 結果のリスト表示・編集・削除・手動追加 |
| 登録 | 倉庫No/列No/段Noを入力して登録 |
| 登録履歴 | 過去の登録データの閲覧・検索・手動同期 |

## プロジェクト構成

```
app/src/main/java/com/crossvision/f/
├── ui/                  # 画面（Activity / ViewModel / Adapter）
│   ├── login/           # ログイン
│   ├── process/         # 工事・工程選択
│   ├── recognize/       # 画像認識
│   ├── camera/          # カメラ
│   ├── confirm/         # 認識結果確認
│   ├── register/        # 登録
│   └── library/         # 登録履歴
├── data/                # データ層
│   ├── local/           # Room Database / DAO
│   ├── model/           # エンティティ定義
│   └── repository/      # リポジトリ
├── ocr/                 # OCR 関連
│   ├── OcrProcessor.kt          # ML Kit テキスト認識
│   └── ProductCodeValidator.kt  # 製品コードバリデーション
└── sync/                # オフライン同期
    ├── SyncManager.kt           # 同期制御
    └── SyncWorker.kt            # WorkManager ワーカー
```

## セットアップ

### 必要環境

- Android Studio Koala 以降
- JDK 17
- Android SDK (API 26 以上)

### 手順

1. リポジトリをクローン
   ```bash
   git clone https://github.com/iput04-isono/sevenstar.git
   ```

2. Android Studio で `CrossVisionF` フォルダを開く
   - **File → Open** からプロジェクトを選択

3. Gradle 同期を実行（自動で開始されます）

4. エミュレータまたは実機で実行

## 製品コード仕様

### 使用可能文字

| 種別 | 文字 |
|------|------|
| 英大文字 | A - Z |
| 英小文字 | a - z |
| 数字 | 0 - 9 |
| 記号 | `+`  `-`  `.`  `/`  `_`  `[`  `]`  スペース |

### コード例

```
1C-X1Y1, 2C-X3Y3, 1-K[-200-1, 1ELP75-1, 2EP175-5,
3SB40-8, 3SCB35-1, B1SCB100-30, B2SCB40-10
```

> **注意**: 先頭識別子（`Xa1`, `Ya1` 等）は OCR 認識時に自動的に除去されます。
